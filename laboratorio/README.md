# Laboratorio estadístico reproducible

Los scripts de esta carpeta generan análisis ejecutables sobre los CSV de la
capa Oro. Los resultados son estadísticas descriptivas y diagnósticos; no
sustituyen mediciones de campo ni recomendaciones agronómicas.

## Ejecutar

```powershell
python laboratorio/e1_series.py
python laboratorio/e3_multivariado.py
python laboratorio/e2_factorial.py
python scripts/export_frontend_data.py
```
