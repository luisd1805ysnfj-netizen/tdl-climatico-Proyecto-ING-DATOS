# tdl-climatico-Proyecto-ING-DATOS
"Observatorio de Inteligencia Climática y Gestión de Riesgos Agrícolas para el Estado de Colima (Tecomán, Colima y Manzanillo)."El observatorio recopila, procesa y audita de manera continua series de tiempo meteorológicas históricas y pronósticos a mediano plazo provenientes de fuentes abiertas (Open-Meteo y SMN/CONAGUA).
